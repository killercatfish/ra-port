- 2026-10-27 · Claude · Raised the default iOS deployment target from 13.0 to 15.0 in `ios/CMakeLists.txt`. Xcode 27 rejects anything below 15.0 ("supported deployment target versions is 15.0 to 27.1.x"), which made every CMake compile check fail and SDL's configure stop with "Threads are needed".
- 2026-10-27 · Claude · Adopted the UIKit scene life cycle on iOS. Apps linked against the iOS 27 SDK fail to launch without it ("UIScene life cycle is required for apps built with this SDK"), and SDL2 2.32 has no scene support. Fix: a scene manifest in `ios/Info.plist.in` naming `RedAlertSceneDelegate`, plus code in `PORT/IOS/src/ios_app_delegate.m` that hooks `-[UIWindow makeKeyAndVisible]` to give SDL's scene-less windows the app's window scene (or holds them until the scene connects) and forwards `sceneDidBecomeActive:` to the existing landscape request. SDL itself is untouched. Moving to SDL3 would be the long-term fix but is a much bigger change.
- 2026-10-27 · Claude · `scripts/build_ios_debug.sh --device` now passes `-allowProvisioningUpdates` to xcodebuild. Without it, automatic signing can't create the first development profile ("No profiles for ... were found").
- 2026-10-27 · Claude · Made the iOS bundle ID a CMake cache variable, `RA95_IOS_BUNDLE_ID` (default unchanged: `com.raport.redalert`), used by both the Xcode attribute and `Info.plist.in`. Upstream's ID is already registered to another Apple team; Josh's builds pass `-DRA95_IOS_BUNDLE_ID=com.killercatfish.redalert`.
